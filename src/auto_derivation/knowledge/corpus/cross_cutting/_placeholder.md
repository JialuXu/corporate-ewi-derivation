# cross_cutting/ — 行业无关的通用风险知识

此目录由业务专家增量沉淀。建议写法：每篇 markdown 一个主题，
heading 层级 `# 主题` → `## 触发场景` → `## 业务解读` → `## 例外情形`。

候选主题示例（仅占位，待业务补）：

- 财务舞弊典型信号（虚增收入 / 关联交易 / 资产质量伪装）
- 资金流红线（夜间大额转账 / 关联方资金循环 / 异常贸易资金流）
- 司法关联传染（被执行案件传染、限消令、法人变更预警）
- 监管口径变化（如 2020 收入准则、2022 数据安全法对客户披露的影响）

文件名以 `_` 开头会被 loader 跳过（本文件即是占位）。
